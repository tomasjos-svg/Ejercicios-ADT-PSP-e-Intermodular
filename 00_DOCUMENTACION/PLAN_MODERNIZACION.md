# Plan de modernización

## Prioridad alta

1. Revocar cualquier clave de API que hubiera estado incrustada en el workspace original y generar una nueva.
2. Unificar JDK 21, codificación UTF-8 y Maven Wrapper en los proyectos canónicos.
3. Sustituir rutas, credenciales, puertos y nombres de servicio codificados por configuración externa.
4. Incorporar instrucciones reproducibles de creación de bases de datos y datos de prueba.

## Prioridad media

1. Añadir JUnit 5 a los ejercicios elegidos para evaluación.
2. Aplicar `try-with-resources` en ficheros, JDBC y sockets.
3. Homogeneizar paquetes, nombres de clases y convenciones Java.
4. Separar enunciado, solución docente y pruebas automáticas.
5. Marcar ejemplos mínimos, prácticas obligatorias y ampliaciones.

## Prioridad evolutiva

1. Crear un proyecto final de ADT y otro de PSP desde IntelliJ para demostrar portabilidad sin abandonar Eclipse.
2. Añadir Docker Compose a las prácticas con Oracle, MySQL o MongoDB.
3. Incorporar rúbricas ligadas a RA/CE y listas de comprobación para el alumnado.
4. Mantener un catálogo anual con versión de JDK, dependencias y estado de ejecución.
