# Mapa orientativo de resultados de aprendizaje y criterios de evaluación

Este mapa sirve para localizar evidencias prácticas. La correspondencia definitiva con cada CE debe realizarse con la normativa y la programación docente vigentes.

| Módulo | RA | Evidencias presentes | Uso sugerido |
|---|---|---|---|
| ADT | RA1 | Ficheros, flujos, XML/JSON, serialización y acceso secuencial/aleatorio | Ejemplos breves, ejercicios progresivos y pruebas de lectura/escritura |
| ADT | RA2 | JDBC, conexiones, sentencias, consultas y actualización de bases relacionales | Prácticas con Oracle/MySQL y control de errores/transacciones |
| ADT | RA3 | Persistencia ORM con Hibernate y JPA | Comparar solución nativa Hibernate y solución JPA |
| ADT | RA5 | Acceso a bases de datos documentales | Práctica integradora con MongoDB |
| ADT | RA6 | Componentes de acceso y servicios REST | Proyectos Spring Boot y API REST |
| PSP | RA1 | Creación, ejecución y comunicación de procesos | Procesamiento de ficheros mediante procesos separados |
| PSP | RA2 | Hilos, sincronización, semáforos, locks, atomics, executors y futures | Secuencia de ejemplos más prácticas de productor-consumidor |
| PSP | RA3 | InetAddress, URL, TCP, UDP, multicast y serialización por sockets | Progresión cliente-servidor y servidores concurrentes |

## Criterios de selección de evidencias

- Identificación y uso correcto de las API implicadas.
- Gestión explícita de excepciones y cierre de recursos.
- Corrección funcional y reproducibilidad de la ejecución.
- Explicación del comportamiento, no solo entrega de código.
- Pruebas con casos normales, límites y errores.
- Documentación de dependencias, configuración y decisiones técnicas.
