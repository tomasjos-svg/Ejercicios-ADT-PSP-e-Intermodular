## Importación y ejecución en Eclipse

1. Use **File > Import > Existing Projects into Workspace**.
2. Seleccione esta carpeta como directorio raíz y marque el proyecto.
3. Si contiene `pom.xml`, ejecute **Maven > Update Project**.
4. Configure **JDK 21** en *Installed JREs* y revise los servicios externos necesarios.
5. Ejecute una de las clases principales detectadas mediante **Run As > Java Application** o **Spring Boot App**.
